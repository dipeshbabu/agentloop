# Diagram icons

AgentLoop's interlocking circuit mark and the outline icons are original project artwork.
The framework logos are used beside their names to identify supported integrations.

| Logo | Source | License |
|---|---|---|
| Python | [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/python.svg) | [CC0 1.0](icon-licenses/simple-icons-CC0.txt) |
| OpenAI | [Lobe Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/openai.svg) | [MIT](icon-licenses/lobe-icons-MIT.txt) |
| LangGraph | [Lobe Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/langgraph.svg) | [MIT](icon-licenses/lobe-icons-MIT.txt) |
| CrewAI | [Lobe Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/crewai.svg) | [MIT](icon-licenses/lobe-icons-MIT.txt) |

The path geometry is retained in `brand-icons.mjs`; size and color are set for the
diagrams. `diagram-icons.mjs` supplies shared icon mappings to the SVG and Remotion
renderers. Logos identify their respective projects and do not imply endorsement.
