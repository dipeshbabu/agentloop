# Support

AgentLoop is maintained as an open-source project. Community support is provided
on a best-effort basis and does not come with response-time or availability
guarantees.

## Choose the right channel

- **Usage and setup:** Check the [README](README.md), integration guide in
  [`docs/INTEGRATIONS.md`](docs/INTEGRATIONS.md), and production guide in
  [`docs/PRODUCTION.md`](docs/PRODUCTION.md) first. If the documentation does not
  answer the question, use the focused usage-question issue form.
- **Reproducible bugs:** Use the bug report issue form and include the AgentLoop
  version, Python version, operating system, minimal reproduction, expected
  behavior, and relevant sanitized output.
- **Feature ideas:** Use the feature request form. Explain the use case before
  prescribing an implementation.
- **Security vulnerabilities:** Follow [SECURITY.md](SECURITY.md). Never disclose
  a vulnerability in a public issue.
- **Code of Conduct reports:** Follow the private process in
  [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Protect sensitive data

Agent traces can contain prompts, model output, tool arguments, URLs, identifiers,
and credentials. Replace them with synthetic data before sharing logs, trace
files, screenshots, or database records. Maintainers may remove unsafe content
and close reports that cannot be investigated without exposing someone else's
data.

## What maintainers can help with

Maintainers can clarify documented behavior, triage reproducible defects, and
review focused feature proposals. They cannot debug private applications without
a minimal reproduction, guarantee compatibility with unsupported forks, or
provide emergency production support through the public issue tracker.
